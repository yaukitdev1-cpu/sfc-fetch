Circular to Licensed Corporations and Associated Entities
Electronic Submission of Financial Returns

Effective date of new submission regime
The legislative process of the Securities and Futures (Financial Resources) (Amendment)
Rules 2008 (“FRR Amendment Rules”) was completed on 18 June 2008. The Amendment
Rules, gazetted on 25 April 2008, will come into effect on 1 November 2008. A copy of the
Amendment Rules is enclosed for your reference (Annex 1).
The FRR Amendment Rules will require all Licensed Corporations (“LCs”) to submit their
financial returns to the SFC electronically by means of an online communication system
approved by the SFC using a revised 1 financial return template in Microsoft Excel
spreadsheet with effect from 1 November 2008.
For LCs that submit financial returns on a monthly basis, the first return to be submitted
electronically under the new submission regime is the one for the position ended 31 October
2008. For LCs that submit their returns semi-annually, they should start the electronic filing
for the December 2008 return.
For the avoidance of doubt, the submission deadline remains unaffected whereby LCs have
21 calendar days to submit their financial returns.

Preparatory work
Technical requirements
You should, as a matter of priority, ensure that your computers and network connections can
meet with the baseline hardware and software specifications contained in Annex 2. Please
contact our e-FRR System Helpdesk hotline on (852) 2283 6883 if you have any questions in
this connection.
It should be noted that submitting returns via FinNet using the Hongkong Post e-Cert
(Organisational) certificate is one of the three accepted modes and thus LCs already adopting
such mode will not be affected (except that revised financial return template should be used)
but they can switch to other modes of electronic submission if they so prefer.

Explanatory Note
These Rules amend the Securities and Futures (Financial Resources) Rules
(Cap. 571 sub. leg. N) (“the principal Rules”) to require all licensed corporations
to submit their financial returns to the Securities and Futures Commission (“the
Commission”) electronically.
2.

Section 2 amends section 56 of the principal Rules to require a licensed

corporation to submit a financial return to the Commission electronically by
means of an online communication system approved by the Commission, and to
sign the return by way of attachment to the return of the digital signature or
electronic signature of its responsible officer or of another officer approved by
the Commission for the purpose.
3.

Section 3 amends section 58 of the principal Rules to require the

Commission to issue directions and instructions for the use of the online
communication system approved by it.

Baseline Specifications of Computer System for e-submission of e-FRR return
In order to be able to support the e-submission of e-FRR return using the SFC e-Certificate,
responsible officers and officers approved by the Commission to sign a return should ensure
they are accessible to a computer system with the following baseline specifications:
PC Hardware Requirement:
IBM compatible personal computer;
Pentium IV 2.0 GHz CPU or above;
100MB free hard disk space or above;
512MB system memory or above;
USB 2.0 slot; and
10/100/1000BaseT Ethernet network interface card;
PC Software Requirement:
Microsoft Windows 2000/ XP/ Vista;
Microsoft Internet Explorer 6.0 or above or FireFox 2.0 or above;
Microsoft Excel 2000 and/or 2003; and
SUN Java Runtime Environment 1.3 or above;
Network Connection Requirement:
Broadband Internet connection (for submission through Internet); or
FinNet Ethernet Link 1 service (for submission through FinNet).
